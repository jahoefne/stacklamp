# stacklamp

A parametric, 3D-printable floor lamp: a metal rod wrapped in an LED strip stands in a printed base, surrounded by two stacks of identical transparent PETG tube segments whose colours you mix per band. Configure the lamp in the browser and download print-ready 3MF/STL files.

Live: https://jahoefne.github.io/stacklamp/

## Develop

```bash
npm install
npm run dev        # http://localhost:5173/stacklamp/
npm test
npm run build
```
